## How this course teaches

**Python is our tool, not our goal.** Every episode teaches one *core idea* that works in any language. We learn it in Python, build it step by step, and show where it lives beyond Python, so when the tools change, you don't start over.

Every build follows the same rhythm:

**PLAN → PREDICT → RUN → CHECK → EXPLAIN**

The habits we practice every week:
1. Understand the problem before you type.
2. Take small steps and run often.
3. Predict, then check.
4. Treat errors as information: read the last line of the traceback first.
5. Verify, don't trust (your code, AI assistants, tutorials, and me).
6. Leave it reproducible: *Restart session and run all* before you call it done.

## How every week works

1. **Watch** the episode: one core idea, one build, one bug we break on purpose and fix.
2. **Open the notebook** in Colab: free, in your browser, no install.
3. **Do one mission level:**
   - **Starter** (~10 min, no GitHub): run the notebook, change one thing, post your result in the YouTube comments.
   - **Core** (30–45 min): the real coding task, saved to your fork of this repo.
   - **Stretch** (60–90 min): a portfolio extension or a "rebuild it another way" challenge.
4. **Solutions** arrive in each episode folder **7 days after** the episode. Try first.
